# Roadmap

1. **Foundation** — monorepo, web/API bootstrap, local infrastructure and quality gates.
2. **Identity & Memory Core** — authentication, workspace/RBAC, PostgreSQL RLS, sources, memories, evidence, entities, audit and private object storage. Core backend delivered through MEM-021.
3. **Capture Engine** — manual note capture and source library (MEM-022); binary file import and upload UX (MEM-023).
4. **Ingestion Pipeline** — durable job orchestration, parsing, OCR, transcription and chunking.
5. **Intelligence Engine** — evidence-grounded extraction, normalization, temporal updates and contradiction handling.
6. **Knowledge Graph** — entity resolution, deduplication and temporal relations.
7. **Hybrid Recall** — lexical, vector, entity and temporal retrieval with grounded citations.
8. **Timeline and proactive intelligence** — user-controlled reminders and contextual surfacing.
9. **Connectors** — Gmail, Drive, Outlook and Calendar with explicit scopes and revocable consent.
10. **GDPR controls and production readiness** — export, retention, erasure, billing, mobile, desktop, observability and operational hardening.
