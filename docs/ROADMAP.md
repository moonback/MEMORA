# Roadmap

1. Foundation: monorepo, web/API bootstrap, local infrastructure and CI.
2. Identity & Memory Core: authentication, workspace/RBAC, PostgreSQL RLS and tenant isolation, sources, memories, evidence and entities.
3. Capture Engine: manual capture and file imports.
4. Ingestion Pipeline: parsing, OCR, transcription and chunking.
5. Intelligence Engine: extraction, normalization and contradiction handling.
6. Knowledge Graph: entity resolution and temporal relations.
7. Hybrid Recall: lexical, vector, entity and temporal retrieval with grounded citations.
8. Timeline and proactive intelligence.
9. Connectors: Gmail, Drive, Outlook and Calendar.
10. GDPR controls, billing, mobile, desktop and production hardening.
